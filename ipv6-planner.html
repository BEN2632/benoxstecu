IPv6 Prefix Planner

Rencanakan pembagian parent prefix IPv6 menjadi subnet dengan panjang prefix baru. Perhitungan memakai BigInt 128-bit.

Rencana Prefix

Parent → subnet baru.

IPv6
Contoh: 2001:db8:abcd::/48.
Maksimal 512 subnet ditampilkan per generate.
Contoh cepat

Rumus

Subnet bit = new prefix − parent prefix
Maksimum subnet = 2^subnet bit
Kapasitas subnet = 2^(128 − new prefix)

Tidak ada broadcast address pada IPv6, sehingga seluruh alamat dalam prefix dapat dipakai.

Belum ada rencana

Tentukan parent network, prefix baru, dan jumlah subnet. Daftar subnet beserta kapasitas alamatnya akan tampil di sini.
