Metode Subnetting

Pilih salah satu pendekatan.

FLSM
FLSM menghasilkan subnet berukuran sama. Jumlah subnet akan dibulatkan ke pangkat 2 terdekat.
Contoh
Prefix dipilih dari kebutuhan host: host bit = ceil(log2(host + 2)), lalu prefix = 32 − host bit.
Contoh

Rumus FLSM

Bit pinjam = ⌈log2(jumlah subnet)⌉
Prefix baru = prefix + bit pinjam
Host usable = 2^host bit − 2

Contoh: /24 dibagi 4 subnet → pinjam 2 bit → /26 → 62 host per subnet.

Belum ada subnet

Tentukan network induk dan kebutuhan subnet atau host, lalu tekan Generate. Tabel subnet lengkap akan tampil di sini.
