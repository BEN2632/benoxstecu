Masukkan alamat IPv4 beserta prefix CIDR atau subnet mask. Kalkulator menampilkan NA, HA, SUB1, SUB2, host range, broadcast, kelas, dan biner secara lengkap.

Input Perhitungan

Prefix atau subnet mask — isi salah satu.

IPv4
Boleh langsung dengan CIDR, contoh 10.10.10.10/11.
CIDR pada kolom IP diprioritaskan. Jika kosong, prefix dipakai; jika prefix kosong, subnet mask dikonversi menjadi prefix.
Contoh cepat

Catatan Istilah

HA (Host ID) adalah bagian alamat IP di luar network address, dihitung dari subnet mask aktual (SUB2).

SUB1 subnet mask default kelas, SUB2 subnet mask aktual sesuai prefix.

NA = IP AND Mask
BOARD = NA OR Wildcard
