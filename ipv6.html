Ketentuan IPv6

IPv6 memakai 128 bit yang ditulis sebagai 8 grup hextet. Tidak ada subnet mask desimal dan tidak ada broadcast address.

Network = Address AND Prefix Mask
Total = 2^(128 − prefix)

Gunakan /64 untuk LAN standar dan /48 untuk site allocation.

Hasil Perhitungan IPv6

128-bit arithmetic menggunakan BigInt.

Setiap langkah memakai alamat yang sudah tervalidasi, sehingga hasil ekspansi dan kompresi konsisten.

Global Unicast (2000::/3) dipakai untuk alamat publik. Link-Local (fe80::/10) hanya berlaku di satu link. ULA (fc00::/7) setara private address. Multicast (ff00::/8) menggantikan broadcast.

Prefix /64 menyisakan 64 bit untuk interface identifier, sesuai standar SLAAC.
