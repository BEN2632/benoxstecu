Tentang BenoxJK

Network address & subnetting calculator dengan penjelasan langkah demi langkah.

BenoxJK

BenoxJK adalah toolkit jaringan berbasis browser untuk menghitung IPv4, IPv6, FLSM, VLSM, dan perencanaan prefix IPv6. Setiap hasil disertai proses perhitungan sehingga dapat dipakai sebagai media belajar, bukan sekadar kotak hitam.

Seluruh perhitungan berjalan di perangkat Anda menggunakan JavaScript. Tidak ada backend, tidak ada upload data, dan tidak ada dependensi database.

Catatan Teknis

Aritmetika IPv4 memakai integer 32-bit tanpa floating point untuk operasi AND/OR mask, sehingga network dan broadcast akurat.

IPv6 memakai BigInt 128-bit agar tidak kehilangan presisi pada alamat dan kapasitas besar.

VLSM mengurutkan kebutuhan host menurun, menyejajarkan blok pada batasnya, lalu memverifikasi tidak ada overlap dan tidak melewati broadcast jaringan induk.

Prefix khusus /31 dan /32 ditangani sesuai RFC 3021 (tanpa pengurangan network/broadcast).

Penyimpanan hanya berisi modul, input, prefix, ringkasan, dan waktu. Hasil dapat dihitung ulang dari input.

Pertanyaan Umum

Tidak. Seluruh perhitungan berjalan di browser. LocalStorage hanya dipakai untuk riwayat dan preferensi sidebar pada perangkat Anda.

HA (Host ID) adalah bagian alamat IP di luar network address, ditampilkan sebagai nilai 4 oktet. Host range adalah alamat yang dapat dipakai perangkat, yaitu NA + 1 sampai broadcast − 1.

Hasil mengikuti standar pengalamatan IP umum dan dapat menjadi acuan. Tetap verifikasi dengan perangkat atau dokumentasi vendor sebelum diterapkan di lingkungan produksi.
